# Mermicorn Graphic AI

**Shared visual system** for clothing, gaming, listings, travel cards, and branding.

## 1. What this project does
Provides visual-generation workflows, brand systems, mockups, asset manifests, and design QA so every vertical can produce consistent, high-quality visuals.

## 2. Who it is for
Cherry (especially ravewear and commerce packaging) and any vertical needing portfolio-ready imagery.

## 3. What exists today
Foundation structure and shared contract.

## 4. What is planned
Complete visual asset pack for one ravewear concept, brand system tokens, mockup pipelines, and design QA checklists.

## 5. What it does not claim
Does not replace human creative direction. AI assists; Cherry decides.

## 6. First proof artifact
A complete visual asset pack for one ravewear concept (front/side/back + detail + colorways).

## 7. Shared Mermicorn services
Primary consumer of this service: cherry-ravewear-studio. Also used by commerce, travel cards, and gaming visuals.

## 8. Information that remains private
Unpublished source files and raw design masters live in the private vault or mermicorn-private-ops.
